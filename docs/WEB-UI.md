# 本地 Web 仪表盘

2026-10-28：用户明确授权 React UI，选择本地 Web 仪表盘；CQU Moe Design 1.1.0。此文覆盖 SPEC 1.1 中 Web 延期的相应范围，不改变旧 SDK/CLI 验收记录。

## 当前范围（U01 + U02）

- 概览：已配置账号、已缓存课程、任务进度与需处理状态；没有数据时给出明确起步入口。
- 课程：搜索、平台筛选、账号选择、主动刷新与分页；查看 SDK 返回的课程目录。未知进度不显示虚构百分比。
- 任务：课程目录中选择资源，配置学习/视频导出/普通作业导出/课件/课堂参数，预览后明确开始。任务中心查看进度、事件、项目结果与文件，暂停、取消、恢复，或只读核对不确定结果。答题编辑、交卷和发布讨论未纳入 U02。
- 账号：新增本地账号、扫码登录、取消登录。会话存在不代表平台在线认证有效。
- React 页面复用 AppShell、ContentContainer、PageHeader、PageState、基础组件、ThemeProvider 和 Toaster；桌面/手机共用，浅深主题和系统主题。

## 边界

`apps/web/src` → 同源 `/api` → `apps/web/server` → SDK 正式入口与 `/node`。平台业务只在 SDK 中。Web 与 Agent CLI 是 SDK 的两个消费者，不依赖彼此的交互层。

本机服务仅监听回环地址，验证 Host/Origin，突变要求 JSON；账号、缓存和 SDK 数据都经 Zod 校验。密钥/Cookie 不进入浏览器或日志；复用 `LEARNING_HOME` 与 CLI 写锁，旧数据库缺密钥时拒绝生成替代密钥。首版不向平台自动查询，不安装后台 daemon。

独立部署、多用户身份、云端 Runtime 和桌面/手机原生封装留待后续。未来原生壳可复用 React 视图和 HTTP DTO；本轮不预建备用抽象。

## 任务执行与恢复

- Web 服务驱动 SDK `jobs.advance`，保留本机写锁与同一个 client。当前同一数据目录只执行一个任务；先暂停当前任务，再启动另一个任务。保持本地服务运行即可，页面可以关闭。
- 学习参数、资源/课堂范围在服务端再次校验；预览与确认使用同一个 SDK executor。学习遇题暂停；课堂加入与恢复均明确提示会产生签到记录。智慧树倍速按课程类型限制。
- 单次预览有效 10 分钟；同一预览重复确认返回同一启动结果。初始化结果未确认时不自动重发。服务重启后预览失效，先查看任务中心再重新预览。
- 恢复使用原 job 与 SDK checkpoint；进程中断的 export/live 在独占锁内恢复，学习写入不确定时先 reconcile。课堂重签到在 SDK 既有 metadata 中先记录 pending，再发请求；响应未知或进程中断保持 uncertain，不重新签到。
- 暂停/关闭服务发出取消信号，等待 SDK 收尾后释放锁；SDK 未支持中断的短暂请求仍需等待结束。已有锁无法确认是否过期时不抢占。
- 导出由 SDK 保存到本地 ArtifactStore；浏览器只能下载对应账号任务中登记的文件，下载前核对长度和 SHA-256。PDF 复用 `/render-node`，不在浏览器拼装文件。
- 未完整解码的题目、人工安全验证仍需在教学平台处理，再回本页恢复。不能从平台证明的写入结果保留为 uncertain。

## 验收

API 使用临时目录、真实 SQLite 和本机 HTTP，验证正常与异常合同、账号隔离、锁和跨源保护。浏览器验证导航、搜索、账号表单、任务详情、空/错/加载、390/768/1440 双主题与 320 重排。测试数据仅由测试注入，产品中无演示数据或假成功计时器。

执行命令、截图与未验范围记录于 PROGRESS；编译通过不等于真实平台验收。
