# CLI 使用体验 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. 用户尚未选择执行方式；不得自行并行修改。步骤用复选框记录，未执行项保持未勾选。

**实施状态（2026-09-28）：** UX01–UX09 已落地，独立评审 7 项已修复；实际测试和裁定见 [PROGRESS](../../PROGRESS.md)。下列清单保留实施前的验收设计，执行记录以 PROGRESS 为准。

**Goal:** 为全部现有 CLI 命令提供一致的交互补参、中文终端 UI 和自动化输出，并明确保存偏好。

**Architecture:** 保留 Commander 的命令树与现有 SDK handlers。CLI 内添加少量共享输入/输出函数，让向导进入同一命令流程；任务显示复用 SDK 事件，不新增协议或通用工作流框架。

**Tech Stack:** Node 24.11.1、pnpm 11.19.0、TypeScript 5.9.3、Commander 15.0.0、Clack、Zod 4.6.5、按需 cli-table3、现有 Vitest。

**Spec:** [CLI 体验设计](../specs/2026-09-28-cli-ux-design.md)、[SPEC 1.1](../../SPEC.md)、[APPS 1.1](../../APPS.md)。体验差异按前者实施，其余边界继续遵守后两者。

## Global Constraints

- 仅 `packages/sdk` 与 `apps/cli` 两个 workspace；无 Web、React、Ink、Cloudflare、daemon、动态插件或通用审批引擎。
- SDK 负责平台协议；UI、配置、命令解析、输出 schema 放 CLI。只复用已证实的 SDK 能力。
- 固定 Node 24.11.1、pnpm 11.19.0、TypeScript 5.9.3、Commander 15.0.0、qrcode 1.5.4；新增直接依赖实际核验后精确锁定。
- DTO 使用 Zod + z.infer；新 CLI DTO 直接使用与 SDK 相同的 Zod 4.6.5，不依赖隐式传递依赖。
- 测试先失败后实现，保留严格 fixture 请求方法/地址/参数/headers/body/error-envelope 校验及未登记请求失败。
- 不运行真实平台登录/学习/答题/发帖/交卷或付费模型；真实考试完全不触碰。离线成功不等于业务验收。
- 在隔离工作树执行，不覆盖主工作区的访谈日志或其他改动，不 reset/clean，不未经授权 push/merge/deploy。
- 本文 UX01–UX09 是本次明确指定的 T25/T26/T31 体验改造分步，不写入原 tasks.json，不新增 T27–T30，不重置既有任务状态。
- 本地提交前逐次核对有效 git user.name/user.email，使用原身份；缺失即停止提交，不替用户配置。

## Review Focus

1. 全局机器格式放在错误参数后、文件名含 --json/空格/中文：仍正确解析，无装饰混入结果，UX01/UX04 验证。
2. 多账号重名课程、失效默认账号、跨账号 draft/job：不能选错对象或把保存偏好当显式授权，UX03/UX04/UX07/UX08 验证。
3. 未知总量、SDK 合并事件、慢管道和 EPIPE：不造百分比，不无限缓冲，结果可判定中断，UX01/UX06 验证。
4. 提示时按 Ctrl+C、直播题过期、写入响应丢失：不漏清理、不提交旧题、不自动重试，UX02/UX06/UX07 验证。
5. 中文长标题、32 列终端、TERM=dumb、OSC 控制符、NO_COLOR：可读、可操作、不执行终端注入，UX02/UX04/UX09 验证。
