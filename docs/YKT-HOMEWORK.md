## 修复前核对的现状

- `runtime/node/render.ts` 的 `font.decode` 无条件报告 `MISSING_RUNTIME`；现有 `font-match.ts` 只有向量匹配函数。`doctor` 如实报告 Canvas 解码器尚未实现。
- `content/html.ts` 检查 `textfonts`，旧参考实现与其字体样本使用 `xuetangx-com-encrypted-font`；现有归一化函数没有接入雨课堂作业读取路径，图片仅保留 alt。

## 旧版值得保留的设计及边界

- 下载与生成草稿共用 `fetch_exercise`，字体解混淆放在这个共用读取入口，明文题不额外下载字体。
- 每份作业有 Markdown 和数据快照；草稿包含题干/选项注释；按课程/章/小节组织，避免同名作业相互覆盖。
- 旧版正则剥 HTML 会丢图片与结构，不能照搬；低置信字保留乱码但去掉加密标记，也不能被新系统认作完整明文。
- 参考目录存在三份跨请求字体子集与 Noto 参考字体。新 Node 实现已对三份样本验证相同句子，固定 Bun 运行时对一份样本复验；它们不足以证明全量字体准确率。
- 旧版 `homework.py` 明确标注本人作答字段形态未验证；普通作业展示与 `backfill.py` 对标准答案还使用不同字段。新实现不能把旧版猜测当协议，也不能将“提交成功”说成“答案正确”；本次不扩展未要求的自动答题功能。

## 用户流程

1. 显式选择雨课堂 profile，并给 `homework download` 传入课程或资源 key；课程内全部作业使用 `--all`。
2. 下载所选作业，得到按课程/章节/作业组织的题面、图片与带注释的简洁草稿；报告完整、部分完成与失败的具体题目。
3. 用户在 YAML 中填写答案；未填答案保持空，不默认选择第一项。
4. 给 `homework apply` 传单份草稿，或传目录并加 `--all`；预览账号、作业、题目及答案，只提交本次 `--dry-run/--yes` 确认且通过完整性/题目版本校验的题目。
5. 已提交、题目变化、不完整及结果不确定分别说明；结果不确定时先核对，不自动再次提交。

批量下载把无法解析的资源及原因放入 `data.failed`，其余作业继续导出；全部资源失败时 `job` 为 null，不创建空任务。目录批量 apply 将非法 YAML、非本账号草稿等本地文件错误放入 `data.skipped`，只预览或提交其余通过校验的答案。存在失败或跳过项时，包括 `--dry-run`，退出码为 4；全部草稿不可用时仍返回逐项原因。单文件输入错误继续直接报错。取消、权限/会话错误和不确定写入不作为普通单项失败继续执行。

重复下载与草稿保留的取舍见 [ADR 0002](adr/0002-ykt-homework-workspace.md)。

## 字体与内容支持

- 字体解析采用精确版本 `opentype.js@2.0.0`；通过字形轮廓比对识别加密 span 内的文本，支持 `textfonts` 与 `xuetangx-com-encrypted-font`。普通文本不套用映射，匹配分数不足或候选歧义时保留 `【未解码】`，不猜字。
- 参考字库为 [Noto Sans CJK SC Regular 2.004](https://raw.githubusercontent.com/notofonts/noto-cjk/Sans2.004/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf)，SIL OFL 1.1，16,437,364 字节，SHA-256 `2c76254f6fc379fddfce0a7e84fb5385bb135d3e399294f6eeb6680d0365b74b`。首次需要时下载到本机 `cache/fonts/`，每次复用前校验；字体不进入 Git。
- 本地图片支持 PNG/JPEG/GIF/WebP，逐个限定大小并验证内容签名；SVG、data URI 或不可信主机返回的图片标记缺失。公式保留正文 TeX（`$...$`、`$$...$$`、`\(...\)`、`\[...\]`）、上/下标与基础 MathML；未支持的 MathML 保留可读符号并标为不完整，阻止对应题目提交。
- 新草稿顶部仅需填写 `answers`，题干/选项为注释，底部 `metadata` 管理 scope、题型与内容指纹。简答和未知题型保留空答案，因未核实提交协议，不自动构造请求。
- SDK 负责读取、解码、图片、指纹、草稿转换和提交前复核；CLI 负责显式选择/全选、文件落盘、机器可读预览及确认。每题执行前再次读取最新内容；已有作答、内容变化或缺失不发送。写入结果不确定立即停止整批，不重发。

## 关键回归场景

- 同一题干以三份不同混淆字体返回时，解码文本与题目身份保持一致；只改变选项文字/顺序/图片时必须按真实内容变化处理。
- 题干或选项有混淆标记而缺字体、下载失败、字体损坏、匹配不唯一时，不得变成完整明文；其余正常题保留。
- Markdown 内图片引用能离线打开；公式、上/下标、换行与选项完整；不可把带 HTML 标签的原文直接称为 plainText。
- 多章/小节中出现同名作业，或标题包含路径字符、大小写与 Unicode 归一化差异时，不覆盖其他作业或越过输出目录。
- 第一次下载后填写答案，再次下载仍保留答案；题目变化另存版本，旧答案不自动绑定新题；下载失败/取消不删除原草稿。
- 简洁草稿四种题型、空答案、非法选项、未知题型、重复题号、错误账号与旧格式导入均有明确结果。
- 命令可处理单份和课程 `--all`；空范围/取消不启动任务；单份失败后批量结果明确报告，完整题可继续。
- 提交前显示本次完整预览；未填、已提交、不完整和版本不匹配的题目不会发送；发送后响应丢失保留 uncertain，不自动重交。
